主页结构：
- 首页：展示武昂达的个人主页入口、时间、本周数据和导航。
- 关于：介绍智能感知工程专业、摄影、美食、音乐和生活记录。
- Canvas 工作台：利用 Canvas API 展示课程待办和 Canvas 通知。
- 摄影：展示个人摄影主题和相册。
- 美食大测评：把交大附近美食分成“夯爆了、夯、人上人、npc、拉”五档，其他区域敬请期待。
- 音乐：放了陪伴过很久的几首歌，有唱机动画、播放控制和全站声波背景。
- 数据：展示一周学习、摄影、美食、咖啡、步数等小数据。
- 彩蛋：标题是“和另一个我聊两句”，通过本地后端调用 DeepSeek API 生成对话。
- 小游戏：最后一页是 DDL 闪避战。

当前项目背景：
- 这是“人工智能理论与应用”课程个人主页作业。
- 页面参考了个人主页和 Dashboard 的布局思路，但内容、数据和交互是自定义的。
- Canvas 工作台、音乐播放器、DeepSeek 彩蛋 Agent 和小游戏是后续增强功能。
