# 武昂达个人主页作业说明

项目名称：**我的数据小馆**

课程作业：用 Vibe Coding 打造个人主页

## 一、主页简介

这是一个围绕“我自己的真实生活数据和兴趣痕迹”制作的个人主页。主页不是单纯的自我介绍，而是把个人信息、一周生活数据、摄影、美食、音乐、Canvas 待办、AI Agent 和小游戏整合成一个可浏览、可交互的小型个人展馆。

主页主要包含以下页面：

1. **首页**
   展示个人标签、头像、主页入口和几个核心数据概览。

2. **关于我**
   介绍姓名、专业、个人主页制作动机、AI 参与痕迹和隐私边界。

3. **Canvas 工作台**
   通过本地后端读取 Canvas 待办和通知，用来展示课程 DDL 与未读消息。

4. **摄影观察**
   展示个人摄影作品集，用照片记录校园、街道、夜晚和日常片段。

5. **美食大测评**
   收录交大附近 9 家真实吃过的店，包括图片、地点、价格、菜品和个人评价。

6. **音乐歌单**
   内置个人常听歌曲和音乐播放器，包含播放、暂停、切歌、进度和音量控制。

7. **一周生活数据**
   使用一周真实/手动记录的小数据进行可视化，包括学习时长、摄影素材数、美食记录、咖啡杯数和步数。

8. **彩蛋 Agent**
   通过本地 DeepSeek 后端实现“网页版武昂达 agent”，可以用个人语气和访问者聊天，并限制隐私、账号和密钥相关问题。

9. **主页打砖块小游戏**
   将主页里的文字、照片和卡片变成砖块，玩家移动挡板打碎砖块。通关后会触发隐藏成就和彩纸彩蛋。

## 二、作业要求对应情况

### 1. 自我介绍区

已包含姓名、专业、头像、个人标签、主页说明和个性化简介。

### 2. 数据可视化区

已包含“一周生活数据”页面。数据维度包括学习、摄影、美食、咖啡和步数，并提供指标切换、柱状图和每日状态说明。

### 3. 交互彩蛋

已包含多个交互：

- 点击头像显示吐槽
- 点击语录切换句子
- 日夜主题切换
- 摄影集切换
- 美食地图和美食详情弹窗
- 音乐播放器
- DeepSeek Agent 对话
- 主页打砖块小游戏与通关彩蛋

### 4. 个性化与原创性

页面素材和内容来自个人兴趣与生活：摄影照片、美食测评、歌单、一周生活数据、Canvas DDL 场景和个人语气 Agent。整体不是模板式自我介绍，而是围绕“摄影、美食、音乐、DDL 和 AI 协作”组织的个人主页。

## 三、打开方式

### 方式一：直接打开静态主页

双击根目录下的：

```text
index.html
```

这种方式可以查看大部分静态页面和前端交互，包括首页、关于我、摄影、美食、音乐、数据可视化和小游戏。

注意：Canvas 工作台、实时步数和 DeepSeek Agent 需要本地后端支持。如果只直接打开 `index.html`，而没有启动后端，这些 API 功能会显示未连接或不可用提示。

### 方式二：一键打开主页并自动启动后端

双击根目录下的：

```text
open-homepage.cmd
```

这个文件会自动执行以下操作：

1. 检查本机是否安装 Node.js 和 npm。
2. 第一次运行时自动安装 `server` 目录下的依赖。
3. 自动启动本地后端。
4. 自动打开 `index.html`。

这是推荐的本地演示方式。

### 方式三：手动启动后端

如果希望手动运行后端，可以在命令行中执行：

```powershell
cd server
npm install
npm start
```

后端默认运行在：

```text
http://localhost:3000
```

## 四、后端功能说明

`server/server.js` 提供以下增强功能：

1. **Canvas 工作台 API**
   用于读取 Canvas 待办、课程任务和未读消息。需要在 `server/.env` 中配置 `CANVAS_TOKEN` 等信息。

2. **DeepSeek Agent API**
   用于支持“和另一个我聊两句”的对话彩蛋。需要在 `server/.env` 中配置 `DEEPSEEK_API_KEY`。

3. **步数上传 API**
   支持通过手机快捷指令或自动化工具上传今日步数，再由主页读取显示。

## 五、目录结构

```text
index.html
个人主页主文件。

open-homepage.cmd
Windows 一键打开脚本，可自动启动后端并打开主页。

assets/images
头像和通用图片资源。

assets/photos
摄影页面使用的照片素材。

assets/food
美食测评图片。

assets/audio
音乐播放器使用的 MP3 文件。

assets/data
前端数据文件，包括 food_reviews.js 和 playlist_data.js。

server
本地 Node.js 后端，用于 Canvas、DeepSeek Agent 和步数上传。

server/agent_data
Agent 的人格、语气样例、边界和主页上下文。

docs
作业要求、Agent 访谈问题、步数上传说明和相关材料。
```

## 六、提交与隐私说明

不应提交以下内容：

- `server/.env`
- API Key
- Canvas Token
- `node_modules`
- 真实账号、密码或其他隐私信息

如果只需要静态展示，提交 `index.html` 和 `assets` 等前端文件即可。

如果需要展示 Canvas 工作台和 Agent 对话，需要同时保留 `server` 目录，并在本地配置环境变量后运行后端。
