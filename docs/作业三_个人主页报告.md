## 一、作品概述

本次作业我制作了一个名为“我的数据小馆”的个人主页。相比单纯介绍姓名、专业和兴趣，我更希望这个主页像一个可以逛的小展馆：里面有我的一周生活数据、摄影作品、美食测评、常听歌单、Canvas DDL 工作台、网页版个人 Agent，以及最后的小游戏彩蛋。

这个主页想呈现的自己不是一个很正式的“简历式形象”，而是一个真实一点、松弛一点、带点吐槽的人：会赶 DDL，会拍照，会吃饭，会听歌，也会一边嫌 AI 不懂人话，一边继续用 AI 改页面。

## 二、页面结构与功能说明

### 1. 首页与自我介绍

首页展示了头像、个人标签、主页入口和几个核心数据概览。关于页进一步说明了我的姓名、专业、年级、主页制作动机和 AI 参与痕迹。

我没有把自我介绍写成正式简历，而是用了“主页使用说明书”的方式，保留了一些个人语气，比如吐槽 DDL、说明 AI 参与痕迹、强调 Agent 不会泄露隐私和密钥等。

### 2. Canvas 工作台

Canvas 工作台是一个本地后端增强功能。它通过 `server/server.js` 请求 Canvas API，读取课程待办和未读消息，并在主页中展示。这个功能来自我真实的 DDL 场景：我经常需要看课程任务和截止时间，所以把它做成一个主页里的工作台。

由于 Canvas Token 涉及隐私和安全，真实密钥不会提交到 GitHub。项目中只保留 `.env.example` 作为配置示例。

### 3. 摄影观察

摄影页展示了我拍摄的校园、街道、夜晚和日常片段。这个部分不是单纯堆照片，而是希望通过照片表现我平时观察生活的方式：比如路灯、街角、校园里的片段，以及一些普通但有记忆点的瞬间。

### 4. 美食大测评

美食页收录了交大附近 9 家真实吃过的店，包括图片、店名、菜品、地点、价格和个人评价。我没有采用很正式的餐厅评分口吻，而是用了更接近日常聊天的表达，比如“夯爆了”“npc”“人上人”等标签。

这个页面对应的是我对“好吃”的真实判断：除了味道和价格，同行的人、当时的状态和记忆点也会影响我对一家店的评价。

### 5. 音乐歌单

音乐页内置了我常听的歌曲，包括孙燕姿、毛不易、邓紫棋、周杰伦等歌手的歌。播放器支持播放、暂停、切歌、进度条和音量控制。音乐播放时，页面还会出现声波背景和唱片动画，让这个页面更像一个小型个人播放器。

### 6. 一周生活数据可视化

数据页是本次作业要求中的核心部分。我选取了一周生活数据作为可视化对象，包括：

| 数据维度 | 含义 | 为什么选它 |
| --- | --- | --- |
| 学习时长 | 每天学习/写作业的大致时间 | 反映课程压力和 DDL 状态 |
| 摄影素材 | 每天拍摄或整理的照片数量 | 反映我的兴趣和观察习惯 |
| 美食记录 | 每天记录的吃饭/探店次数 | 对应美食测评页面 |
| 咖啡杯数 | 每天喝咖啡的杯数 | 反映日常提神和学习状态 |
| 步数 | 每日步数 | 反映生活节奏和活动量 |

可视化形式采用指标切换 + 柱状图 + 每日状态说明。这样做的原因是：数据量不大，没必要做复杂仪表盘；柱状图更直观，也方便比较一周内每天的变化。

### 7. “另一个我”Agent 彩蛋

Agent 页面是我最想突出的交互之一。它不是普通客服式问答，而是尝试模拟“网页版武昂达”的语气。为了让它不要太像 AI，我额外整理了 Agent 访谈问题、语气样例、边界规则和主页上下文，让它能用更接近我本人的方式回答摄影、美食、音乐、大学生活和主页相关问题。

同时我也设置了边界：隐私、账号、Token、API Key 等内容不能回答。这个部分既是交互彩蛋，也是我对 AI 角色边界的一次尝试。

### 8. 主页打砖块小游戏

最后一页原本是比较普通的小游戏，后来我觉得不够有趣，于是改成了“主页打砖块”：把主页里的摄影照片、文字、音乐、Canvas DDL、DeepSeek Agent 等内容变成砖块，玩家用挡板把它们打碎。通关后会触发“网页拆迁队”隐藏成就和彩纸彩蛋。

这个游戏比单纯的“接东西/躲东西”更贴合主页本身，因为玩家打碎的不是随便生成的方块，而是这个个人主页中的内容碎片。

## 三、关键 Prompt 与迭代过程

### 1. 初始主页搭建

**Prompt 思路：**

希望 AI 帮我做一个个人主页，但不是模板式简历，而是一个能体现个人生活和兴趣的“数据小馆”。

**AI 输出：**

AI 先生成了基础页面结构，包括首页、自我介绍、数据区和交互区。

**我的修改：**

我继续要求它加入更个人化的内容，比如摄影、美食、音乐、Canvas DDL 和吐槽式语气。否则页面会比较像普通模板站。

### 2. 数据可视化迭代

**Prompt 思路：**

要求页面展示一周生活数据，并且可以切换不同指标。

**AI 输出：**

AI 生成了基础柱状图和指标按钮。

**我的修改：**

我把数据维度调整成更贴近自己的生活：学习、摄影、美食、咖啡和步数。这样数据不只是为了完成作业，而是真的能体现我这一周的状态。

### 3. Agent 语气纠偏

**Prompt 思路：**

我不希望 Agent 像客服，也不希望它一直说很正式的话，而是希望它像“另一个我”。

**AI 输出：**

一开始的回答还是偏 AI 助手，语气比较礼貌但不够像我。

**我的修改：**

我补充了 Agent 访谈问题、语气样例和边界说明，例如回答要短一点、可以吐槽、不要高大上的礼貌用语、不要泄露隐私和密钥。

### 4. 小游戏改版

**Prompt 记录：**

“最后一页游戏太无聊了，你能不能换个游戏。”

AI 先给了一个分类小游戏，但我觉得还是不够好玩。

接着我提出：

“把网页里的文字、照片、卡片变成砖块来打。”

**AI 输出：**

AI 把最后一页改成了主页打砖块，把摄影、美食、音乐、Canvas 和 Agent 变成砖块。

**我的修改：**

我继续要求加入通关彩蛋，并指出游戏有点卡顿。于是后续优化了动画方式，把球和挡板从每帧修改 `left/top` 改成使用 `transform: translate3d(...)`，减少布局计算。

### 5. GitHub 发布准备

**Prompt 思路：**

我需要把项目上传到 GitHub，所以要求 AI 帮我检查 `.gitignore` 和 README。

**AI 输出：**

AI 检查后发现原本 `.gitignore` 没有忽略 `server/.env`，这会导致 Canvas Token 或 DeepSeek API Key 泄露。

**我的修改：**

我补充了环境变量忽略规则，并把 README 从 txt 改成 GitHub 可识别的 `README.md`。

## 四、踩坑复盘

### 1. 页面一开始容易变成模板

AI 很擅长生成结构完整的网页，但如果只说“做一个好看的个人主页”，它很容易生成一个通用模板。这个模板可能视觉上还行，但不像我。

我的解决方式是不断加入具体生活内容：摄影照片、美食测评、歌单、Canvas DDL、个人语气和小游戏。这样页面才慢慢变得不那么空泛。

### 2. Agent 容易有 AI 味

Agent 一开始最大的问题是太像普通 AI 助手，说话比较客气、完整、正确，但不够像人。我后来通过访谈问题和语气样例告诉它：回答短一点，可以吐槽，不要总是解释，不要像客服。

这让我意识到，做 AI 角色不只是给它一个名字，而是要给它边界、语气、样例和上下文。

### 3. 后端功能和直接打开文件有冲突

静态主页可以直接打开，但 Canvas 工作台和 DeepSeek Agent 需要本地后端。如果只交一个 HTML，老师可能看到部分功能不可用。

我的解决方式是保留两种打开方式：静态打开用于展示大部分页面；一键脚本 `open-homepage.cmd` 用于自动启动后端并打开主页。同时在 README 中说明哪些功能需要后端。

### 4. 小游戏一开始不好玩

原来的小游戏只是简单接东西/躲东西，和主页关系不强。后来我改成“主页打砖块”，让砖块本身来自网页内容，这样游戏就更像主页彩蛋，而不是硬塞进去的小游戏。

### 5. 动画卡顿

打砖块刚做出来时有一点卡顿。原因是球和挡板每一帧修改 `left/top`，可能触发布局计算。后来改成 `transform: translate3d(...)`，并加入 `will-change` 和 resize 防抖，动画更顺滑。

### 6. GitHub 提交前的隐私风险

我一开始以为只要 Canvas API 不泄露就行，但后来发现 DeepSeek API Key 即使余额不多，也不应该公开。GitHub 上可能有自动扫描密钥的机器人，所以 `.env` 必须忽略，只保留 `.env.example`。

## 五、如果重做一次，我会怎么改

如果重新做一次，我会先确定三个东西：

1. **个人主题**
   先明确主页到底要表现什么样的自己，而不是先堆功能。

2. **数据口径**
   一开始就确定数据从哪里来、记录多久、哪些数据真实可靠，避免后期再补说明。

3. **迭代记录**
   每次关键修改都保存截图和 Prompt，这样最后写报告会轻松很多，也更能体现我对 AI 的主导过程。

Prompt 策略上，我也会尽量少说“做得好看一点”，多说具体要求，比如“标题距离顶部减半”“小游戏改成打砖块”“球和挡板移动改成 transform，减少卡顿”。这些具体反馈比抽象评价更容易让 AI 改对。

## 七、总结

这次作业让我感觉到 Vibe Coding 最有价值的地方不是“一键生成网页”，而是可以把一个很模糊的想法快速做成能看的版本，然后在不断吐槽、纠偏和补充中变成更像自己的作品。

AI 负责把想法变成初稿，但真正决定作品气质的是我不断提出的具体要求：哪些地方不像我、哪个游戏不好玩、哪段文案太假、哪个功能需要隐私边界。最后这个主页虽然还有可以继续打磨的地方，但它已经不只是一个作业页面，而更像一个带着我个人生活痕迹的小展馆。
